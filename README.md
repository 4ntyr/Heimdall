# Heimdall (production name: **HMDL**) 

is a terminal-only, peer-to-peer, end-to-end encrypted messenger for Windows
and Linux. No central server, no runtime dependencies — a single self-contained
executable. Peers authenticate by cryptographic identity fingerprints 
(X25519 + Ed25519 + AES-256-GCM), never by display name.

See `docs/protocol.md` and `docs/threat-model.md` for the security design.
See `docs/deployment.md` for build and run instructions.
